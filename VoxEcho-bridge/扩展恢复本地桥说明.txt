# 扩展侧请恢复「本地桥」播放路径

offscreen.js 中合成应请求：

  POST http://127.0.0.1:5005/speak
  body: { "text": "...", "voice": "zh-CN-XiaoxiaoNeural", "rate": "+0%" }

返回 audio/mpeg 二进制，再 URL.createObjectURL 播放。

若当前 offscreen 仍是 FRONTEND_PLAY / Edge WS 逻辑，请换回原先
fetchChunk → 127.0.0.1:5005 的版本（你仓库里改前端之前的 offscreen.js）。

# 📖 VoxEcho - 网页版电子书朗读插件

VoxEcho 是一款专为 Chrome 浏览器打造的免安装（绿色版）电子书辅助朗读工具，支持在网页端阅读时提供高质量的语音朗读体验。

### 🌟 核心特性
* **支持平台**：Google Play Books、Koodo Reader（网页版）。
* **支持语言**：中文、英语、西班牙语、日语、韩语。
* **快捷控制**：支持使用主键盘或小键盘的半角句号 `.` 一键暂停与恢复朗读。

---

### 📥 安装与使用步骤

#### 1. 解压项目
下载 `VoxEcho.zip` 压缩包并解压为 `VoxEcho` 文件夹，将其移动并保存至合适的本地目录（*请勿删除或随意移动该目录*）。解压后包含以下文件结构：
* `VoxEcho-extension/`（浏览器插件目录）
* `VoxEcho-bridge.exe`（本地桥接服务）

#### 2. 安装 Chrome 插件
1. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并按回车。
2. 开启右上角的 **开发者模式**。
3. 点击左上角的 **加载已解压的扩展程序**，选择解压出来的 `VoxEcho-extension` 文件夹。
4. 安装成功后，建议在浏览器右上角的插件栏中将 VoxEcho 固定（Pin）以便快捷调出。

#### 3. 启动本地桥接服务
双击运行 `VoxEcho-bridge.exe`。
* 首次运行时，程序可能会自动补全或初始化运行环境，请耐心等待。
* 初始化完成后，服务将在后台常驻运行。你可以根据需要将其设置为开机自启。

#### 4. 开始使用
1. 打开 Google Play Books 或 Koodo Reader 网页版并进入书籍阅读页面。
2. 点击 VoxEcho 插件图标打开 Popup 控制面板，此时面板将自动抓取并显示当前页面的文本。
3. 选择所需的朗读音色与语速，点击 **开始朗读**。
4. 朗读过程中，按键盘上的句号键 `.`（主键盘或小键盘均可）即可随时暂停或恢复。
